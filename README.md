# Cement Bag Counter

A computer vision project for detecting, tracking, and counting cement bags using YOLO and OpenCV.

## Features

- Cement bag detection using YOLO
- Object tracking using BoT-SORT
- Counting cement bags when they cross a predefined line
- Real-time video processing
- YOLO custom-trained model

## Technologies

- Python
- OpenCV
- Ultralytics YOLO
- BoT-SORT
